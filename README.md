# Student-Career-and-Internship-Tracker
A professional-grade career tracking platform designed to help students manage internship applications, track skill progression, and analyze application success rates. Built with React, Next.js, Node.js, Express, and Supabase PostgreSQL. Features AI-powered skill extraction via NVIDIA NIM LLMs.

## Vercel Deployment Note
When deploying the frontend on Vercel, ensure **Root Directory** under Project Settings -> Build and Deployment is set to `client`.
